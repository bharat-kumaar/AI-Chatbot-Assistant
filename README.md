# QnA-chatbot-with-chat-history

A simple Q&A chatbot with chat-history functionality built in Python.  
It allows users to ask questions, retains conversation context (history), and returns answers accordingly.

## 📌 Features

- Maintains a chat history so the bot can reference earlier messages in the conversation.  
- Lightweight Python implementation — easy to set up and extend.  
- Uses minimal dependencies (see `requirements.txt`).  
- Ideal starting point for building a more advanced conversational agent or Q&A system.

## 🧰 Technologies & Dependencies

- Python (compatible version: 3.x)  
- Listed in `requirements.txt`  
- Main application file: `app.py`

> To install dependencies:  
> ```bash
> pip install -r requirements.txt
> ```
